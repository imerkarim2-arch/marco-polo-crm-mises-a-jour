Installez le CRM de la société en quelques minutes

Clients, ventes, stock et documents de l'équipe, sur votre ordinateur. Suivez les 4 étapes ci-dessous : vous n'aurez à le faire qu'une seule fois.

Ouvrez cette page sur votre ordinateur Windows. Le CRM s'installe sur un ordinateur, pas sur un téléphone. Envoyez-vous ce lien (par e-mail ou WhatsApp Web), puis ouvrez-le sur l'ordinateur.
Télécharger Marco Polo CRM
Dernière version · Windows 10 et 11 · environ 80 Mo

Avant de commencer : vous devez avoir reçu de votre gérant votre adresse e-mail de connexion et un mot de passe.
Dans les dessins, ce qu'il faut cliquer est entouré en rouge.

1

Téléchargez le fichier

Cliquez sur le bouton vert Télécharger Marco Polo CRM, en haut de cette page.

Si votre navigateur affiche un avertissement sur le fichier, choisissez Conserver. Dans Microsoft Edge : …, puis Conserver, puis Conserver quand même. Le fichier vient de votre société, il est sans danger.

Ouvrez-le

Ouvrez le fichier téléchargé (en bas ou en haut à droite du navigateur, ou dans le dossier Téléchargements).

Windows affiche souvent une fenêtre bleue « Windows a protégé votre ordinateur » : c'est normal pour un logiciel fait pour une seule société. Cliquez sur Informations complémentaires, puis sur Exécuter quand même.

Installez

Laissez le dossier proposé et cliquez sur Installer, puis sur Fermer. Une icône Marco Polo CRM apparaît sur le bureau, et le CRM s'ouvre.

4

Connectez-vous

Saisissez l'adresse e-mail et le mot de passe reçus de votre gérant, puis Se connecter.

Pour choisir votre propre mot de passe : cliquez sur Mot de passe oublié ? sur cet écran. Vous recevrez un e-mail avec un lien.

Connexion Adresse e-mail Mot de passe Se connecter
C'est tout. Le CRM se met ensuite à jour tout seul : quand une nouvelle version est prête, un bouton « Mettre à jour maintenant » apparaît en bas du menu. Vous n'aurez plus jamais à revenir sur cette page.

Un problème pendant l'installation ? Contactez votre gérant.
